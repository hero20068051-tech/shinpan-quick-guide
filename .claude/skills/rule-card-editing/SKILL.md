# 競技規則カード編集 Skill

このSkillは、`index.html` 内の `rules` 配列にある 68 枚の競技規則カードを、安全に 1 枚ずつ編集する作業専用です。

作業前に `docs/MASTER_BIBLE.md` と `CLAUDE.md` を基準資料として確認すること。

---

## 使用する場面

ユーザーが、

- 次のカード
- ○○のカードを直す
- 競技規則カードを編集する

などの指示をしたとき。

---

## 手順

1. 現在の `git status` を確認する
2. `index.html` の `rules` 配列を確認する
3. カード数が 68 枚か確認する
4. 指定された `title` を完全一致で検索する
5. 対象カードの現在コードを確認する
6. 直前と直後のカードタイトルを確認する
7. ユーザーが決めた内容だけ編集する
8. `git diff` を確認する
9. カード数が 68 枚のままか再確認する
10. 構文上の問題がないか確認する
11. 対象以外が変更されていないか確認する
12. 結果を日本語で簡潔に報告する

---

## 禁止事項

- カード追加
- カード削除
- カード入れ替え
- `title` 変更
- 複数カードの勝手な一括修正
- 似たカードを推測して編集
- 関係ない UI 変更
- 大会要項かんたん入力の変更
- ついでのリファクタリング
